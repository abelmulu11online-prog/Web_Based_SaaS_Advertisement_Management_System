# types/

Shared type definitions for the frontend.

Currently using plain JSDoc for type hints. If the project migrates to TypeScript
these files will become `.ts` / `.d.ts` definitions.

## Planned type files (future phases)

| File | Purpose |
|------|---------|
| `user.js` | User and advertiser profile shapes |
| `advertisement.js` | Ad listing data shape |
| `subscription.js` | Subscription plan and status shapes |
| `location.js` | GPS coordinate and address shapes |
