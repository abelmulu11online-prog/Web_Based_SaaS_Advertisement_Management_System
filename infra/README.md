# infra/

Infrastructure configuration — Docker, Nginx, and environment templates.

## Folders

| Folder | Purpose |
|--------|---------|
| `docker/` | Dockerfiles for frontend and backend |
| `nginx/` | Nginx reverse-proxy config for production |
| `env/` | Environment variable templates (`.env.example` files) |

Full Docker setup will be implemented in Phase 9 (Deployment).
